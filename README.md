# 📌 Overview

ROADWATCH AI is a modern chatbot-based web application designed to simplify road infrastructure monitoring and public complaint management.

Unlike traditional dashboards or websites, the entire system operates through an intelligent AI chatbot interface.

Users can:

- View road infrastructure details
- Report road problems
- Track complaint status
- Perform AI-based road damage detection

This project is designed for:

- Hackathons
- Smart city solutions
- AI portfolio showcases
- LinkedIn project demonstrations

---

# ✨ Features

## 🛣 Road Details

Displays infrastructure information such as:

- Road Name
- Thickness
- Contractor
- Budget
- Last Repair Date

### Sample Data

- GST Road
- 150mm Thickness
- ABC Infra Pvt Ltd
- ₹2.4 Cr Budget
- January 2025 Repair Date

---

## ⚠ Report Road Problem

Users can submit complaints with:

- Problem type
- Description
- Severity level
- Image upload

### Complaint Example

```text
RW-1024
```

Complaints are stored using browser localStorage.

---

## 📍 Track Complaint

Users can track complaints using complaint ID.

Displays:

- Complaint status
- Severity
- Date
- Timeline progress

If complaint ID is invalid, the chatbot shows an animated error response.

---

## 🤖 AI Damage Detection

Simulated AI-based road analysis using uploaded image filename detection.

### Detection Logic

- pothole → Pothole detected
- crack → Crack detected
- water → Waterlogging detected
- otherwise → Road condition normal

### AI Output

- Detection result
- Confidence score
- Severity score
